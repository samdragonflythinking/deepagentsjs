# Dragonfly Lenses

This directory contains simplified lens prompts for DeepAgents testing.

## Available Lenses

1. **SW

OT** - Strengths, Weaknesses, Opportunities, Threats
2. **PESTLE** - Political, Economic, Social, Technological, Legal, Environmental
3. **Porter's Five Forces** - Industry competitive forces
4. **Stakeholder Analysis** - Key stakeholders and their interests
5. **Scenario Planning** - Future scenarios and implications
6. **Risk Analysis** - Risks, likelihood, and mitigation
7. **Value Chain** - Value creation activities
8. **Competitive Analysis** - Competitive positioning
9. **Trend Analysis** - Key trends and implications
10. **Game Theory** - Strategic interactions and decisions

## Prompt Pattern

Each lens follows the proven minimal pattern from Phase 1:
- Clear, directive instructions
- Specific output structure
- Explicit file-saving protocol
- No complex examples or thinking tags
- Direct and actionable
