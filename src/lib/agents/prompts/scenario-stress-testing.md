# Analytical Methodology

## Core Analysis Framework

Scenario Stress Testing examines strategy robustness through systematic exposure to alternative futures:

### Core Components

1. **Scenario Development** - Constructing diverse, plausible futures

2. **Strategy Exposure** - Testing plans against each scenario

3. **Vulnerability Assessment** - Identifying failure points and weaknesses

4. **Robustness Evaluation** - Measuring performance across scenarios

5. **Adaptation Design** - Building flexibility and resilience

## Critical Analysis Questions

1. **Scenario Diversity:** Do scenarios cover the range of plausible futures?

2. **Stress Points:** Where does the strategy break under pressure?

3. **Robust Elements:** What performs well across all scenarios?

4. **Early Warnings:** What signals indicate scenario emergence?

5. **Adaptive Capacity:** How can strategy flex with changing conditions?

## Analysis Process

1. **Define Critical Uncertainties:** Identify key drivers of change
2. **Construct Scenarios:** Build 3-4 diverse future states
3. **Map Strategy Elements:** Document current strategic plan
4. **Stress Test Components:** Evaluate each element per scenario
5. **Identify Vulnerabilities:** Find breaking points and gaps
6. **Assess Overall Robustness:** Score cross-scenario performance
7. **Design Adaptations:** Build resilience mechanisms

## Lens Integration Points

**Upstream Connections (Context Setting):**

# Internal Workflow

## Step 1: Critical Uncertainty Identification

- Map external forces affecting strategy
- Identify high-impact, high-uncertainty factors
- Select 2-3 critical axes for scenarios
- Define uncertainty ranges
- Validate with stakeholder input

## Step 2: Scenario Construction

Develop 3-4 distinct scenarios:
- **Scenario names:** Memorable, descriptive titles
- **Narrative:** Coherent story of how future unfolds
- **Key characteristics:** Specific conditions and dynamics
- **Driving forces:** What creates this future
- **Early indicators:** Signals of emergence

## Step 3: Strategy Decomposition

Break strategy into testable elements:
- Core assumptions
- Strategic objectives
- Key initiatives
- Resource allocations
- Capability requirements
- Success metrics

## Step 4: Stress Testing Matrix

For each strategy element in each scenario:
- Performance assessment (thrives/survives/struggles/fails)
- Vulnerability identification
- Adaptation requirements
- Resource implications
- Timeline impacts

## Step 5: Vulnerability Analysis

- Single-point failures
- Cascade effects
- Common vulnerabilities across scenarios
- Time-sensitive weaknesses
- Resource constraints

## Step 6: Robustness Scoring

- Element-level robustness
- Overall strategy resilience
- Best-case/worst-case performance
- Expected value across scenarios
- Regret minimization analysis

## Step 7: Adaptation Strategy

- No-regret moves (work in all scenarios)
- Hedge strategies (insurance against specific futures)
- Option creation (preserve flexibility)
- Trigger points (when to pivot)
- Learning mechanisms (adapt as future unfolds)
